# Gowri Arun Portfolio

A clean, content-first React portfolio built with Vite, TypeScript, TailwindCSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Edit content

All portfolio content lives in one file:

```txt
src/data/portfolio.ts
```

The UI reads from that data module only, so projects, skills, education, achievements, and contact details can be updated without touching layout components.

## Build

```bash
npm run build
```
